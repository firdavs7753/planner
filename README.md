# Планировщик недели

Готовый сайт на чистом HTML/CSS/JS. Данные хранятся в localStorage браузера телефона (только на этом устройстве, никуда не отправляются).

## Как опубликовать через GitHub Pages

1. Зайди на github.com, создай новый репозиторий (например `planner`), публичный.
2. Загрузи в него файлы `index.html` и `manifest.json` (кнопка "Add file" → "Upload files").
3. Зайди в репозитории в Settings → Pages.
4. В разделе "Branch" выбери `main` и папку `/root`, нажми Save.
5. Через 1-2 минуты сайт будет доступен по ссылке вида:
   `https://твой-юзернейм.github.io/planner/`

## Как поставить на телефон как приложение

**Android (Chrome):**
Открой ссылку → меню (три точки) → «Установить приложение» или «Добавить на главный экран».

**iPhone (Safari):**
Открой ссылку → кнопка "Поделиться" (квадрат со стрелкой) → «На экран «Домой»».

Появится иконка, открывается в полный экран, без адресной строки браузера.
